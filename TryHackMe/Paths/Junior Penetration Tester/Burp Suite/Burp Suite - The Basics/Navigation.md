The default navigation is primarily done through the top menu bars, which allow you to switch between modules and  access various sub-tabs within each module.
![[Pasted image 20250924215404.png]]
### Module Section
The top row of the menu bar displays the available modules in Burp Suite.
### Sub- Tabs
If a selected module has multiple sub-tabs, they can be accessed through the second menu bar that appears directly below the main menu.
### Detaching Tabs
You can detach them into separate windows.
