In essence, is a Java-based framework designed to serve as a comprehensive solution for conducting web application penetration testing.
Simply put, Burp Suite captures and enables manipulation of all the HTTP/HTTPS traffic between a browser and a web server.
## Burp Suite Professional
Is an unrestricted version of Burp Suite Community.
- An automated vulnerability scanner.
- A fuzzer/brute-force that isn't rate limited.
- A built-in API to allow integration with other tools.
- Unrestricted access to add new extensions for greather functionality.
- Access to the Burp Suite Collaborator.
## Burp Suite Enterprise
Is primarily utilized for continous scanning.
