The Dashboard screen is divided into four quadrants.
### Tasks
The tasks menu allows you to define background that Burp Suite will perform while you use the application.
In Burp Suite Community, tje default "Live Passive Crawl" task, which automatically logs the pages visited, is sufficient for out purposes in this module.
### Event log
The event log provides information about the actions performed by Burp Suite.
### Issue Activity
It displays the vulnerabilities identified by the automated scanner, ranked by severity and filterable based on the certainty of the vulnerability.
### Advisory 
Provides more detailed information about the identified vulnerabilities, including references and suggested remediations. This information can be exported into a report.
