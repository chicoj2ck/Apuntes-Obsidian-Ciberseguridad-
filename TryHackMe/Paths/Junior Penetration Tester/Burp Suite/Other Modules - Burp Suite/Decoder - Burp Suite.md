The Decoder module of Burp Suite gives user data manipulaton capabilities. As implied by its name, it not only decodes data intercepted during attack but also provides the function to encode our own data, prepping it for transmission to the target.

## Encoding and Decoding with Decoder
- Plain
- URL
- HTML
- Base64
- ASCII Hex
- Hex, Octal, and Binary
- Gzip

## Hashing
HashIn addition to its Encoding/Decoding functionality, Decoder also offers the ability to generate hashsums for our data.

Hashing is a one-way process that transforms data into a unique signature. For a function to qualify as a hashing algorithm, the output it generates must be irreversible.
