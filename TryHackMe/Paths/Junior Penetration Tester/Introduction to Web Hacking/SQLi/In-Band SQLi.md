In-Band SQL Injection is the easiest type to detect and exploit; In-Band just refers to the same method of communication beign userd to exploit the vulnerability and alsot receive the results.
## Error-Based
This type of SQLi is the most useful for easily obtaining information about the database structure, as error message from the database are printed directly to the browser screen.
## Union-Based
This type of SQLi utilisess the SQL UNION operator alongside a SELECT statement to return additional results to the page.
